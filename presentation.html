MILESTONE 01 // OBJECTIVES

為什麼改造？我們要達成什麼目標？

原本的 LINE Bot 深度綁定 LINE Webhook 流程，且依賴本機伺服器。今天我們透過分層架構進行解耦，在完全不破壞原有 LINE 功能的前提下，全面釋放多端應用的能力。

改造前的瓶頸與痛點

  • • 依賴 LINE App：使用者必須打開 LINE 才能互動，無法從瀏覽器直接開啟。
  • • 無法外部整合：Google Sheets、試算表或自動化腳本無法直接呼叫 Bot。
  • • 雲端部署風險：若貿然上傳 Cloud Run，原有的本機終端指令會操作雲端 Linux 容器。

今日達成的四大核心成果

  • ✓ 獨立網頁聊天室：免裝 App，開啟 Google Chrome 即可享受完整 AI 與知識庫。
  • ✓ Google Apps Script 整合：能在試算表格子中下公式 =ASK_BOT("...")。
  • ✓ 共用統一核心：LINE、網頁、GAS 100% 共用相同的 AI、本地知識庫與搜尋能力。
  • ✓ 雲端原生容器化：提供 Dockerfile、Gunicorn 與圖文部署手冊，隨時直上 Cloud Run。

GOOGLE APPS SCRIPT // SHEETS INTEGRATION

Google Apps Script (GAS) 整合與自訂函數

依據您的特別需求，我們建立了標準的 GAS 通訊端點，直接在試算表中打公式即可呼叫 Bot！

試算表格子自訂公式

直接在任意儲存格輸入公式，AI 即刻回答：

=ASK_BOT("請問陳文盛老師開哪些課？")
=ASK_BOT(A2)
GAS 腳本自訂呼叫 (gas_integration.js)
function askBot(prompt) {
  var res = UrlFetchApp.fetch(URL, {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify({ message: prompt })
  });
  return JSON.parse(res.getContentText()).reply;
}
